# Student Score Predictor (Android / Java / TensorFlow Lite)

## Current contents
This is the Android Studio project scaffold. The trained model files are generated by the accompanying Colab notebook.

## Inputs
- studytime: category 1-4 (not exact hours)
- absences: absence count
- G2: previous period grade (0-20)

## Output
- Predicted G3 final mathematics grade (0-20)
